# Airbnb_analysis

## Project Overview
This project focuses on analysing Airbnb Open Data using Python. It aims to understand Airbnb listings, pricing, room types, host performance, and customer preferences. The analysis helps identify patterns in listing distribution, availability, and customer reviews across different neighbourhoods.

## Objectives
- Analyse the distribution of Airbnb listings across neighbourhoods.
- Identify popular room types and property locations.
- Compare listing prices and service fees across neighbourhoods.
- Study host performance using listing counts and customer reviews.
- Analyse customer preferences based on room types and reviews.
- Examine booking availability and cancellation policies.

## Dataset Description
The dataset contains 102,599 records and 26 columns, including:

- **Listing Details:** ID, name, neighbourhood, and room type.
- **Host Information:** Host ID, host name, and identity verification.
- **Pricing:** Price, service fee, and minimum nights.
- **Reviews:** Number of reviews, review rate, and last review date.
- **Availability:** Availability throughout the year and instant booking.
- **Other Details:** Construction year, cancellation policy, house rules, and license.

## Tools & Technologies
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, and Seaborn.

## Analysis Performed
1. **Data Cleaning:** Checked missing values, duplicate records, and data types.
2. **Location Analysis:** Examined listing distribution across neighbourhoods and neighbourhood groups.
3. **Pricing Analysis:** Compared listing prices and service fees across locations and room types.
4. **Host Analysis:** Studied host listing counts and identity verification.
5. **Customer Preferences:** Analysed popular room types and customer reviews.
6. **Availability Analysis:** Examined booking availability and cancellation policies.
7. **Data Visualization:** Used charts and graphs to present important patterns and insights.

## Conclusion
This project provides an overview of Airbnb listings and their characteristics through Python-based data analysis. It helps understand location-wise listing distribution, pricing patterns, host performance, customer preferences, and booking availability. The findings can support better understanding of the Airbnb rental market and its trends.
